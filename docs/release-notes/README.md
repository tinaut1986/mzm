# Release notes

One file per tag, `vX.Y.Z.md`, written before tagging. The release workflow puts
it in the GitHub release body, and the 3DS updater shows it before the player
installs. The rules (language, length, what a stable release must include) are in
`CLAUDE.md`, section "Release notes".

Example (`v0.7.0.md`):

```
- Achievement badges now download on demand and are cached on the SD card.
- RetroAchievements settings moved to the Achievements tab.
- The updater can show what changed before you install.
```
